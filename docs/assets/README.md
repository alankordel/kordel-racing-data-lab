# Captura do dashboard

A imagem `dashboard-overview.png` deve ser uma captura real do Streamlit com os dados de exemplo.

Para atualizá-la:

1. execute `python main.py` ou mantenha os Parquets da sessão de exemplo em `data/gold/session_9839`;
2. inicie `streamlit run dashboard/app.py`;
3. abra a URL local exibida pelo Streamlit;
4. selecione uma visão representativa da sessão e dos pilotos;
5. capture a página e salve como `docs/assets/dashboard-overview.png`;
6. confirme que o README continua apontando para essa imagem.

Não substitua a captura por uma ilustração ou imagem genérica.
